## 📌 Featured projects

### 💸 [NexusPay Engine](https://github.com/Aricode2005/NexusPay-Engine): Enterprise FinTech wallet API
`Node.js` `PostgreSQL` `Apache Kafka` `Redis` `Hugging Face`

An event-driven digital wallet backend.
- **Kafka** decouples ledger updates from notifications, cutting API latency by an estimated 40%
- **Two-step Intent/Execute flow** with PostgreSQL row-level locks and UUID ordering: ACID-safe, no deadlocks, no double-spends
- **Redis** rate limiting, idempotency keys and **JWT** stateless auth to block brute-force MPIN attacks and duplicate retries
- **Agentic AI fraud detection** that watches transaction velocity and freezes suspicious accounts on its own, plus a **RAG assistant** for querying past transactions in natural language

### 🧠 [ExpenseIQ](https://github.com/Aricode2005/expense-tracker-mcp): Agentic AI finance server (MCP)
`Python 3.13` `FastMCP` `aiosqlite` `SQLite`

A production-style MCP backend that exposes **15 financial tools** (CRUD, budgets, analytics) directly to LLMs like Claude.
- Fully **async** with aiosqlite; deployed to a remote cloud environment over **Streamable HTTP**
- Fault-tolerant workflows: the model validates inputs, self-corrects categorisation errors, and reads live dashboards through **MCP Resources**

### 📊 [QuantStream Engine](https://github.com/Aricode2005/QuantStream-Engine): Algorithmic trading backtester
`C++17` `OOP`

- Polymorphic design lets you swap **5+ strategies** (RSI, Bollinger Bands, Z-Score) without touching the core execution logic
- Shared risk-management modules and post-trade diagnostics like the **Hurst Exponent** for market-regime detection
